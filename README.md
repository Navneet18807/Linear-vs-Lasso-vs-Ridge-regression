# Linear vs Lasso vs Ridge Regression

This project demonstrates a comparative analysis of three popular linear models:
- **Linear Regression**
- **Lasso Regression (LassoCV)**
- **Ridge Regression (RidgeCV)**

Dataset: Student Performance Dataset (with features like Previous Scores, Hours Studied, Extracurricular Activities, etc.)

##  What’s inside?

✔ Data Preprocessing  
✔ Encoding & Scaling  
✔ Model Training & Evaluation  
✔ Visualization (scatter plots, heatmap, pairplot)  
✔ Error Metrics: Mean Absolute Error, R² Score  
✔ Model comparison

##  Libraries Used
- pandas
- numpy
- scikit-learn
- seaborn
- matplotlib

##  Result
Each model was trained and tested on the same dataset, and the performance was compared using prediction accuracy and MAE. LassoCV showed regularized results suitable for overfitting control.
